# Лабораторная работа №5 — Основы JavaScript и проектирования компонентов

**Дисциплина:** WEB-программирование  
**Вариант:** №1

## Цель работы

Ознакомление с синтаксисом и возможностями JavaScript, закрепление навыков вёрстки и стилизации, проектирование независимых интерактивных компонентов веб-страниц.

## Реализованные компоненты

1. **Счётчик кликов** (`counter.html`) — увеличение, уменьшение и сброс значения.
2. **Переключатель темы** (`theme.html`) — светлая и тёмная темы с сохранением выбора.
3. **Калькулятор** (`calculator.html`) — четыре арифметические операции и проверка деления на ноль.
4. **Модальное окно** (`modal.html`) — открытие и закрытие диалогового окна.
5. **Форма с валидацией** (`validation.html`) — проверка имени, электронной почты и пароля.
6. **Прогресс-бар** (`progress.html`) — изменение процента выполнения от 0 до 100.
7. **Показать/скрыть пароль** (`password.html`) — переключение видимости пароля.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- DOM API
- Обработка событий
- Регулярные выражения
- LocalStorage

Все компоненты реализованы без сторонних JavaScript-библиотек и фреймворков.

## Запуск проекта

1. Скачайте репозиторий.
2. Откройте файл `index.html` в браузере.
3. Выберите необходимый компонент.
4. Проверьте его интерактивную работу.

Для запуска не требуется установка дополнительных библиотек или серверного программного обеспечения.
